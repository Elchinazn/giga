# ⚽ Футбольный аналитик — Telegram-бот

Бот показывает статистику футбольных лиг и анализирует предстоящие матчи:
форма команд, личные встречи, турнирное положение и вероятностный прогноз
по модели Пуассона (П1/X/П2, тотал больше 2.5, обе забьют, вероятные счета).

Данные — бесплатный API [football-data.org](https://www.football-data.org),
live — [API-Football](https://www.api-football.com) и/или [MyScore](https://www.myscore.ru).

## Возможности

| Команда | Что делает |
|---|---|
| `/start`, `/help` | Справка и выбор лиги кнопками |
| `/leagues` | Список лиг → меню: таблица, матчи, результаты, бомбардиры |
| `/table PL` | Турнирная таблица |
| `/matches PL` | Ближайшие матчи (10 дней) с кнопкой «анализ» у каждого |
| `/results PL` | Результаты за последние 10 дней |
| `/scorers PL` | Топ-10 бомбардиров |
| `/team PL Arsenal` | Место, очки, мячи за игру, форма и последние матчи команды |
| `/analyze <id>` | Полный анализ и прогноз матча |
| `/live` | Матчи в прямом эфире: счёт, минута, удаления; кнопка live-анализа у каждого |
| `/live Англия`, `/live Arsenal` | Поиск live-матчей по лиге или команде |
| `/live myscore`, `/live api` | Взять данные из конкретного источника |
| `/subs` | Матчи, за которыми вы следите |

### Live-анализ матча

- счёт, минута, голы, пенальти, удаления, VAR;
- статистика: владение, удары, удары в створ, xG, угловые и др.;
- **live-прогноз на итог**: П1/X/П2, кто забьёт следующим, вероятность, что голов
  больше не будет, тотал больше 2.5, самые вероятные итоговые счета;
- кнопки «🔄 Обновить» и «🔔 Следить» — бот сам пришлёт гол (с автором), удаление,
  перерыв, начало второго тайма и финальный счёт.

Live-прогноз моделирует оставшиеся голы распределением Пуассона: средняя
результативность лиг × оставшееся время, доля смещается в сторону команды,
которая создаёт больше моментов (xG, иначе удары), а удаление снижает
результативность команды на 25% и повышает у соперника на 25%.

Коды лиг: `PL` (Англия), `PD` (Испания), `BL1` (Германия), `SA` (Италия),
`FL1` (Франция), `DED` (Нидерланды), `PPL` (Португалия), `ELC` (Чемпионшип),
`BSA` (Бразилия), `CL` (Лига чемпионов), `EC` (Евро), `WC` (ЧМ).

## Как работает прогноз

1. По домашней таблице хозяев и выездной таблице гостей считаются сила атаки и
   обороны каждой команды относительно среднего по лиге (с поправкой на малое
   число сыгранных матчей).
2. Ожидаемые голы = атака × оборона соперника × средние голы лиги, с поправкой
   ±10% за форму в последних 5 матчах.
3. Из ожидаемых голов по распределению Пуассона считаются вероятности всех
   счетов до 10:10, а из них — исходы, тотал и «обе забьют».

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Получите бесплатный ключ API: https://www.football-data.org/client/register
3. Установите зависимости и настройте ключи:

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # впишите TELEGRAM_BOT_TOKEN и FOOTBALL_DATA_API_KEY
python main.py
```

### Live-источники

Нужен хотя бы один. Если включены оба, основной — API-Football, а MyScore
используется как запасной (когда кончился дневной лимит или API недоступен)
и по кнопке «Показать с MyScore».

**API-Football** — официальный API, есть события с авторами голов и полная
статистика. Бесплатно 100 запросов в день: получите ключ на
https://dashboard.api-football.com/register и впишите в `API_FOOTBALL_KEY`.
Один опрос подписок тратит 1 запрос на каждые 20 матчей, поэтому при
`LIVE_POLL_SECONDS=120` лимита хватает примерно на один длинный вечер матчей.

**MyScore** — включён по умолчанию (`MYSCORE_ENABLED=1`), ключ не нужен.
Есть все лиги мира и статистика, но нет авторов голов, а минута считается
приблизительно (`~67'`). Важно:

- у MyScore нет публичного API, бот читает внутренний поток данных сайта.
  Правила MyScore запрещают автоматический сбор данных — используйте на свой риск,
  при активном использовании сайт может заблокировать IP;
- формат потока не документирован. Если бот пишет «MyScore ответил ошибкой»,
  откройте myscore.ru в браузере → DevTools (F12) → вкладка Network → фильтр `feed`.
  Из любого запроса возьмите адрес до `/f_1_...` (это `MYSCORE_FEED_URL`)
  и заголовок `x-fsign` (это `MYSCORE_FSIGN`) и впишите их в `.env`.

Подписки на матчи сохраняются в файл `subscriptions.json` (путь меняется
переменной `SUBS_FILE`) и восстанавливаются после перезапуска. Если за время
простоя в матче что-то произошло, бот пришлёт это при первой проверке.
Если файл окажется повреждённым, бот переименует его в `subscriptions.json.broken`
и начнёт с пустого списка.

Часовой пояс для времени матчей задаётся переменной `BOT_TIMEZONE`
(по умолчанию `Europe/Moscow`, например `Asia/Baku`).

Бесплатный тариф API разрешает 10 запросов в минуту. Ответы кэшируются на 5 минут.
Анализ одного матча занимает до 5 запросов.
