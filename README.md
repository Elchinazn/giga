# ⚽ Футбольный аналитик — Telegram-бот

Бот показывает статистику футбольных лиг и анализирует предстоящие матчи:
форма команд, личные встречи, турнирное положение и вероятностный прогноз
по модели Пуассона (П1/X/П2, тотал больше 2.5, обе забьют, вероятные счета).

Данные — бесплатный API [football-data.org](https://www.football-data.org).

## Возможности

| Команда | Что делает |
|---|---|
| `/start`, `/help` | Справка и выбор лиги кнопками |
| `/leagues` | Список лиг → меню: таблица, матчи, результаты, бомбардиры |
| `/table PL` | Турнирная таблица |
| `/matches PL` | Ближайшие матчи (10 дней) с кнопкой «анализ» у каждого |
| `/results PL` | Результаты за последние 10 дней |
| `/scorers PL` | Топ-10 бомбардиров |
| `/team PL Arsenal` | Место, очки, мячи за игру, форма и последние матчи команды |
| `/analyze <id>` | Полный анализ и прогноз матча |

Коды лиг: `PL` (Англия), `PD` (Испания), `BL1` (Германия), `SA` (Италия),
`FL1` (Франция), `DED` (Нидерланды), `PPL` (Португалия), `ELC` (Чемпионшип),
`BSA` (Бразилия), `CL` (Лига чемпионов), `EC` (Евро), `WC` (ЧМ).

## Как работает прогноз

1. По домашней таблице хозяев и выездной таблице гостей считаются сила атаки и
   обороны каждой команды относительно среднего по лиге (с поправкой на малое
   число сыгранных матчей).
2. Ожидаемые голы = атака × оборона соперника × средние голы лиги, с поправкой
   ±10% за форму в последних 5 матчах.
3. Из ожидаемых голов по распределению Пуассона считаются вероятности всех
   счетов до 10:10, а из них — исходы, тотал и «обе забьют».

## Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Получите бесплатный ключ API: https://www.football-data.org/client/register
3. Установите зависимости и настройте ключи:

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # впишите TELEGRAM_BOT_TOKEN и FOOTBALL_DATA_API_KEY
python main.py
```

Часовой пояс для времени матчей задаётся переменной `BOT_TIMEZONE`
(по умолчанию `Europe/Moscow`, например `Asia/Baku`).

Бесплатный тариф API разрешает 10 запросов в минуту. Ответы кэшируются на 5 минут.
Анализ одного матча занимает до 5 запросов.
